# CoolCurve

Native macOS temperature dashboard and optional fan curve for Mac17,16.

Build with `./build.sh` using Apple Command Line Tools. Launch `CoolCurve.app`. The app starts in monitoring mode and requires explicit administrator authorization to enable fan control.

See [usage guide](사용안내.md) and [curve tuning](TUNING.md). SMC code includes the Stats MIT license in `Source/LICENSE-Stats.txt`.

Local experimental software; no guarantee of suitability for other hardware. Build products and runtime logs are not tracked.
